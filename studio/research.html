    Protocol and limits

    Five stratified outer folds provide one held-out prediction per specimen. Within each outer training set, four inner folds select hyperparameters using AUROC. Feature scaling runs inside the training pipelines. The probability error interval uses paired, class-stratified resampling of the fixed predictions and describes conditional variation on this dataset. It excludes retraining variability.

    These results describe an internal benchmark. The previous 114-specimen experiment used the same dataset. Independent validation would require a separate cohort. Exploring thresholds here is descriptive and provides no prospective operating point.
