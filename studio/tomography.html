Reconstruction error

Try the missing-angle experiment

Keep the slice and pass count fixed. Compare 4 angles with 48, then restrict the scan to 90°. Inspect the small structures and record which change affects density error most. The detector records sums along parallel rays. Each solver pass projects its current estimate, compares those sums with the readings and distributes the residuals back to the pixels.

These noise-free, dimensionless measurements come from the same discretized operator used for reconstruction. This is a controlled inverse problem with known ground truth.
