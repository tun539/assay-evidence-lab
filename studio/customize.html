5. Deploy to your own host or custom domain

  
This repository has zero vendor lock-in. A single command python3 scripts/build_site.py --out dist builds the complete site and offline ZIP for any static host:

  

    

      
GitHub Pages (Active)

      
Already configured in .github/workflows/deploy-pages.yml. Push or edit on GitHub to deploy automatically. Add a root CNAME file for your own domain.

    

    

      
Vercel

      
Ready via vercel.json. Import the GitHub repo in Vercel for instant preview URLs on every branch and custom domain SSL.

    

    

      
Netlify

      
Ready via netlify.toml. Connect the repo in Netlify to publish dist/ with clean extensionless URLs automatically.

    

    

      
Cloudflare Pages / Self-host

      
Build command: python3 scripts/build_site.py --out dist · Output directory: dist. Works on any static CDN or S3 bucket.
